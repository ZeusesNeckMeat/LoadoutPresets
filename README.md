# Loadout Presets

A mod that allows you to manage loadout presets in Megabonk with character-linked auto-loading.

## Features

- **Save and Load Loadouts** - Preserve your unlock configurations and switch between them instantly
- **Character Linking** - Link loadouts to specific characters for automatic loading
- **Auto-Load on Character Select** - Linked loadouts automatically activate when you select their character in-game
- **Shareable Loadouts** - Export and share loadout files with friends
- **Custom Names** - Name your loadouts for easy identification

## Installation

Install with a mod manager like r2modman or Thunderstore Mod Manager.

## Usage

### Creating and Managing Loadouts

1. **Access the Menu**: Click the "LOADOUT PRESETS" button in the main menu
2. **Save a Loadout**: 
   - Configure your unlocks in-game however you want
   - Open the Loadout Manager
   - Enter a custom name in the input field (or leave blank for default)
   - Click "SAVE"
3. **Load a Loadout**: Click the "LOAD" button next to any saved loadout
4. **Delete a Loadout**: Click the "DELETE" button next to any saved loadout

### Character Linking

Link loadouts to characters so they auto-load when you select that character:

1. **Link a Character**: 
   - In the Loadout Manager, **left-click** the character button next to a loadout
   - Select the character you want to link
2. **Remove a Character Link**: 
   - **Right-click** the character button next to a loadout

**Note**: Only one loadout can be linked to each character. Linking a character to a new loadout automatically removes it from any previous loadout.

### Sharing Loadouts

1. Click "OPEN FOLDER" in the Loadout Manager
2. Copy the `.json` files you want to share
3. Share them with friends who can drop them into their own LoadoutPresets folder
